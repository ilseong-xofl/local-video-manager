# 현재 제품 범위

기준일: 2026-08-13

## 확정된 결정

- Windows 설치형 Electron 애플리케이션으로 개발한다.
- 개발은 Mac에서, 테스트·installer 생성은 Windows에서 수행한다.
- 각 멤버는 한 번에 하나의 로컬 영상 폴더를 사용하되, 이전에 관리한 폴더 기록은 DB에 보존한다.
- 원본 영상은 각 멤버의 컴퓨터에만 두고 서버로 업로드하지 않는다.
- 다른 멤버의 영상·썸네일·메타데이터는 볼 수 없다.
- 관리자가 별도 서비스에 등록한 계정만 로그인할 수 있다.
- 회사 공인 IP 허용 범위 밖에서도 로그인과 일반 프로그램 사용은 허용하고 캡션
  생성만 차단한다.
- 설치별 `library_id`로 중앙 데이터가 섞이지 않게 논리적으로만 분리한다.
- `library_id`는 로컬 라이브러리 식별자이며 보안 경계는 서버 인증·권한·IP 검사다.
- 소스 저장소와 Windows release artifact는 공개 GitHub 저장소에 둔다.
- 자동 업데이트는 GitHub Releases와 `update.electronjs.org`를 사용한다.
- 업데이트는 자동 확인·다운로드하고 다음 실행 시 자동 적용한다.
- 영상 편집과 캡션 히스토리는 로컬 DB에 유지한다.
- 캡션은 별도 서비스가 OpenAI API로 생성하며 API 키를 Electron에 포함하지 않는다.
- 캡션은 명시적으로 요청할 때마다 새 결과를 생성하며 과거 결과를 자동 재사용하지 않는다.
- 캡션 생성은 사용자별 KST 하루 최대 10회이며 Service가 성공 완료 건을 기준으로
  판정한다.
- 실제 Windows 패키징·업데이트 배포는 서버 연동 검증 후 별도 승인으로 진행한다.

## Phase 1 기능

1. 영상 폴더 선택과 변경
2. 선택 폴더를 포함한 최대 3단계 새 파일·변경 파일 스캔
3. 스트리밍 SHA-256 exact identity
4. 폴더별 위치 이력과 로컬 SQLite scan cache
5. 등록일·수정일 저장, 기간 필터와 오름차순·내림차순 정렬, 파일명 부분검색
6. 썸네일 그리드
7. 로컬 영상 플레이 팝업
8. URL·원문 캡션 등록과 수정 이력
9. 과거 영상 검색과 URL·원문 캡션 복사
10. 로컬 SQLite DB 백업·복원과 영상 폴더 재연결
11. Windows installer와 자동 업데이트
12. 관리자 등록 계정 로그인과 캡션 생성의 회사 네트워크 제한
13. 영상 편집과 캡션 생성 이력
14. 별도 서비스 기반 OpenAI 캡션 생성

## 명시적으로 하지 않는 것

- Electron 내부의 사용자 생성·권한 관리
- Electron bundle에 OpenAI API 키 저장
- 팀 전체 통합 영상 목록
- 영상 원본 업로드·다운로드
- 사용자 간 exact hash 중복 비교
- 유사 영상 판정
- 과거 URL·캡션·다운로드 당시 조회수 자동 복원
- NAS 스캔
